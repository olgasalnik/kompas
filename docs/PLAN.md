# План работы над прототипом «Компас»

Кейс-чемпионат «Клинический компас»: цифровой ассистент врача для ведения пациента с тревожной и депрессивной
симптоматикой. Источники: PDF кейса, полный рабочий документ команды (75 стр.), краткая спецификация MVP.

**Формула продукта:** «Врач решает. Компас помнит, считает, проверяет и вовремя зовёт».

## Что строим

Вариант A из спецификации: **демонстрационный MVP на синтетических данных**, но архитектура под вариант B
(пилот): правила как данные, слой API, журнал, роли.

- Веб-приложение (PWA): один адаптивный интерфейс для телефона пациента и ноутбука врача.
- Работает **без сервера и без интернета** (запасной вариант на демо): данные в браузере, синхронизация
  между вкладками «пациент» и «врач» в реальном времени. Слой `api` можно заменить на настоящий сервер.
- Выкладка на GitHub Pages → ссылка и QR-код на решение для презентации и постера.

Стек: Vite + React + TypeScript, react-router, lucide-иконки, шрифты Golos Text / Manrope (кириллица, локально),
vitest для тестов. Графики — собственные SVG (с отметками визитов, начала терапии, пропусков).

## Модули → 8 задач кейса

| № | Задача кейса | Модуль в прототипе |
|---|---|---|
| 1 | Стандартизированные методы оценки | PHQ-4, PHQ-9, GAD-7 (пациент), ввод HAM-D/HAM-A/MADRS (врач); автоподсчёт, градации, пункт 9 |
| 2 | Рекомендации по терапии | Карточки КР, паспорт «Авиандра» из ГРЛС, метка «ВНЕ ИНСТРУКЦИИ — решение врача» |
| 3 | Риски и нежелательные явления | Чек-лист факторов, правила СТОП / ВНИМАНИЕ, журнал НЯ |
| 4 | Мониторинг динамики | Досье на 30 секунд, графики, «что изменилось», симулятор времени |
| 5 | Самоотчёт пациента | Кабинет пациента: приём, чек-ин ≤ 60 с, шкалы, графики, «Мне тяжело сейчас» |
| 6 | Каналы коммуникации | Чат с карточкой контекста за 7 дней, рабочие часы, нейтральные напоминания |
| 7 | Приверженность | Принял / Пропустил / Позже, причины, индекс за 7 и 28 дней, T-detect |
| 8 | Направление к психиатру | Режим «Терапевт»: PHQ-4 → шкалы → красные флаги → ОБЯЗАТЕЛЬНО / ЖЕЛАТЕЛЬНО |

Сквозное: алертинг (красный / оранжевый / жёлтый, подтверждение, эскалация 10 / 30 мин, журнал и замер
времени), «Почему?» у каждого вывода (правило, версия, источник), реестр источников, согласия, аудит,
режимы ИИ «Наставник / Практик / Тихий», страница соответствия кейсу (8 из 8 функций, 10 из 10 условий).

## 7 демонстрационных сценариев с «Авиандром»

1. Классическое ГТР — показание совпадает. 2. Депрессия доминирует — вне инструкции. 3. Сочетанный приём
(сертралин + дифенгидрамин) — ВНИМАНИЕ. 4. Беременность — СТОП. 5. Красный алерт (пункт 9 = 2) —
эскалация. 6. Пропуски и сонливость — приверженность. 7. Терапевт — тревога и телесные жалобы.
